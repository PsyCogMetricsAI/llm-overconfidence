
# N2：给定汇总信息时可确定的选择风险

状态：执行者推导，待V-MATH。不是实测结果。基础交集计数界、校准与错误识别的区别属于既有知识；本报告是针对本测量问题的条件化整理，不主张首次提出。

## 1. 数据对象及允许变化

固定n≥1道题、每题同为K≥2个选项、每题金标g_i∈{0,...,K−1}、固定item ID全序。概率向量p_i∈Δ_K，预测j_i是最大概率选项（选项并列时取最小索引），c_i=max_j p_ij，y_i=1{j_i=g_i}。题间置信度并列按item ID排序。令1≤k≤n，T_k为前k题，e=Σ(1−y_i)，R_k=k^(-1)Σ_{i∈T_k}(1−y_i)，A=1−e/n，C=n^(-1)Σc_i。

主要概率域是有限实数logits的softmax，即所有概率严格正、c_i<1；允许c_i=1/K（所有logit相同）。另明确讨论闭单纯形允许零概率时的c_i=1，不与有限logits混同。

“可行配置”指在这些数学约束下存在的概率向量，不保证某个现实LLM或训练程序实现全部配置。比较配置时题目/gold/ID保持固定，仅模型概率向量变化。不要求概率已校准；若增加E(Y|c)=c等校准假设，可行集合改变，不能沿用无该假设的可达性结论。

## 2. 平均差及其条件化变体

同题同权的有符号均值差为O=C−A。对完备、不交叠的分箱B_b，n_b=|B_b|，a_b/c_b为箱内均值，则Σ_b(n_b/n)(c_b−a_b)=C−A；空箱按零贡献处理。总体同测度的E[c−E(Y|c)]=E(c)−E(Y)。

改变正负方向或固定量纲只是仿射变换。不同箱等权、分别归一化正负子集、额外置信度权重、拟合概率替代y，都需要另外的等式，不是上述命题。普通ECE保留绝对值、Brier保留平方项，均不属于此处化简。

Groot印刷式是(1/M)Σ_b n_b(a_b−c_b)=(n/M)(A−C)，百分数另有100倍。只有给定n/M时才是该条件下的固定变换；若n/M随模型变化，不能说原始三列[A,C,NCE]必然秩≤2。显式除以n/M所得A−C是我们说明的归一化变体，不冒称作者原式或已核代码。

这一依赖说明给定A、C及已声明尺度后O无新增汇总信息，不说明O不可计算、不可靠、无描述用途或不存在元认知特质。原文映射以V-L通过的literature_matrix为准。

## 3. 已知计数界

记t=|{错误题}∩T_k|。错误总数e，选择题数k；选择外最多放n−k个错误，选择内至多有min(e,k)个错误。因此

max(0,e−(n−k)) ≤ t ≤ min(e,k)，

L0=max(0,e−(n−k))/k ≤ R_k ≤ U0=min(e,k)/k。

可行风险是整数格点t/k，不是有限n时整个实数区间。q=k/n时写为max(0,1−A/q)≤R_q≤min(1,(1−A)/q)。这是集合计数界，不是本研究原创定理。

## 4. 给定A和C：内部均值下界限可达

条件：nA为整数，0≤A≤1，1/K<C<1；金标/ID固定；有限logits；无其他概率校准/题目机制约束。

结论：与(A,C)相容的风险值恰好为第3节界内所有整数格点。因而仅增加内部平均置信度C，不会缩小该计数范围。

证明：
当k<n时，取
ε=(1/2)min{(C−1/K)n/k,(1−C)n/(n−k)}>0，
c_H=C+ε(n−k)/n，c_L=C−εk/n。
于是1/K<c_L<c_H<1，且(k c_H+(n−k)c_L)/n=C。
将固定ID顺序的前k题设c_H，其余设c_L，使T_k固定。
任取整数t满足第3节界，在T_k放t个错误，在其余放e−t个错误；计数界保证两处均装得下。
每题欲正确时j_i=g_i，欲错误时取任意j_i≠g_i；令p_ij_i=c_i，其他K−1项均为(1−c_i)/(K−1)。因c_i>1/K，j_i唯一最大，正确性符合要求。所有概率正且小于1，log p给出有限softmax logits。因此每个t均可达；其余t被计数界排除。
当k=n时所有题取c_i=C，同样构造概率向量；R=1−A为唯一格点。

该结论对给定不同(A,C)均可比较，但不意味着现实中这种最大风险跨度常见，N5负责实际差异。

## 5. 固定完整置信度信息

若固定每题置信度向量h_i∈(1/K,1)（包含题间并列），则T_k由h和ID固定。仍可按第4节方法任意指定y_i而保持各h_i不变，因此给定A和该向量也保留第3节全部格点。仅给定其多重集H约束更弱，结论同样成立。即使保持置信度直方图，也没有给定它与正确性的配对关系。

这里不是说已校准模型也能任意变y；模型概率与正确性关系是未受约束的对象。更完整的置信度与正确性联合信息可以减少范围。

### 5.1 含均匀端点的固定向量：精确条件界

允许h_i=1/K时，令J0={i:h_i=1/K}；此处p_i唯一为均匀向量，j_i=0，因此错误指示z_i=1{g_i≠0}被锁定。令e0=Σ_{J0}z_i，J1为其他自由题，r=e−e0。
可行当且仅当0≤r≤|J1|；否则给定A与该h不相容。令e0T=Σ_{J0∩T_k}z_i，fT=|J1∩T_k|，fU=|J1\\T_k|，则所有可行错误数恰为整数区间：

e0T+max(0,r−fU) ≤ t ≤ e0T+min(r,fT)。

证明：端点题错误固定；r个自由错误分配到fT个已选及fU个未选自由题，用第3节同样计数；其余题用唯一最大概率构造。可达性和不可能性均成立。

如果只给定混合端点多重集H而未固定逐题位置，精确集合为所有不同排列π的上述可行格点集合的并集。空可行排列忽略；全部空则F为空。上下界分别取非空并集的最小/最大值。这个有限排列表达式是精确刻画，不声称已给出大n高效算法或并集必为连续格点。

### 5.2 极端均值/概率域

- C<1/K或C>1、nA非整数、A∉[0,1]：空可行集。
- C=1/K：所有题均匀，y_i=1{g_i=0}完全固定；若其均值不等于A则空，否则R唯一，由ID前k题决定。不能说计数界在固定gold下总可达。
- C=1：有限logits域为空；闭单纯形域允许各题one-hot，c全部并列但y仍可任意指定，按ID选择仍使第3节界可达。
- A=0或1且可行：R分别为1或0，不存在风险不确定性。
- 内部C且全部置信度相同：跨题并列由ID处理，仍可选择每题argmax选项实现任意y，所以第3节界可达；这与C=1/K时选项本身全并列不同。
- k=ceil(n/2)必须使用实际q_n，奇数n不能把k/n当精确.5。

## 6. 两个直观构造与使用边界

例A（同分不同风险）：n=100、K=4、k=50、A=.8；50题置信度.9、50题.7，C=.8、O=0。20错误全在后50题时R=.0，全在前50题时R=.4。以第4节概率向量实现，金标可全固定为0。两模型置信度多重集相同。

例B（较小偏差不能保证较低风险）：仍A=.8、前50题为高置信组。模型甲各组c=.85/.65，C=.75、O=−.05，全部20错误在高组，R=.4；模型乙各组c=.95/.85，C=.9、O=.1，全部错误在低组，R=0。甲signed值更低且|O|更小，但自动处理错误率更高。此处乙信心总体高估，不否认甲在平均偏差上的不同表现。

实用含义是信息与用途对应，不是禁止使用O。对有限已标注题板，如果已知A≥1−qτ，则U0≤τ，总体准确率本身已经能限定选择风险；因此不能说这类汇总信息“永远不能提供任何风险保证”。把样本A外推到未来总体需要额外统计条件，不能用该计数式替代N6的不确定性分析。
